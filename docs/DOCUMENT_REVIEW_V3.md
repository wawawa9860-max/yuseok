### 남은 문제 ①: 합계행 공수 `A61 = 29`

```
천공조서 R61  A열 = 29     ← 실제 데이터는 54행
```

합계열(`J61`, `V61`)은 고쳐졌으나 **공수 칸만 이전 29공 잔재**입니다.
금액에 직접 영향은 없으나, 조서를 읽는 사람이 공수를 오해할 수 있습니다.

### 남은 문제 ②: H-Pile 규격 불일치

| 시트 | 규격 | 단위중량 |
|---|---|---|
| 산출근거 R20 | `H-300x300*10*15` | 94 kg/m |
| 내역서-실행가 R20 | `H-350x350*12*19` | — |

**물량(1,080m)은 같으나 규격이 다릅니다.** 자재 발주·단가 산정에서 어긋납니다.
연결판(`PL-600x200x14`, `PL-600x280x14`)도 H-300 기준으로 맞는지 확인이 필요합니다.

## 3. 도면과의 공수 차이 (여전히 존재)

| | 도면 | 조서 v3 |
|---|---|---|
| H-PILE | `1`~`54` (54공) | 54공 ✅ |
| 무근 | `1-1`~`54-1` 중 **`16-1` 없음** (53공) | `1-1`~`54-1` **54공** |
| 합계 | **107공** | **108공** |

조서 v3 에도 `16-1` 이 그대로 있습니다. 둘 중 하나입니다.

- **도면이 맞다** → 조서에서 `16-1` 을 빼야 합니다 (107공)
- **조서가 맞다** → 도면에 `16-1` 을 그려 넣어야 합니다 (108공)

시스템은 어느 쪽도 임의로 정하지 않습니다. 대조표로 보여주고 사람이 고릅니다 (§8).

## 4. C.T.C 가변에 대한 설계 반영

사용자 확인 사항을 시스템에 고정했습니다.

> "0.47 간격으로 유지가 되는 구간도 있고 유지가 안 되는 구간들이 있어서
>  간격을 좁혀야 하는 상황이 매번 생긴다.
>  그러므로 도면 넘버링에 맞도록 수량을 체크하였다."

### 반영 내용

**① 계산 공수는 참고값이다**

```
총 공수 = 벽면연장 50m ÷ C.T.C 0.47m = 106.4공   ← 참고 추정값
조서 기재 총 공수                      = 108공
실제 도면 넘버링                       = 107공    ← 확정 기준
```

세 값이 모두 다릅니다. **이것이 정상입니다.**
`총 공수`·`H-PILE 본수`·`무근 본수` 는 `is_reference = true` 로 표시되어
**공수·수량 확정 근거로 쓰이지 않습니다.**

**② 계산값과 실제가 달라도 오류가 아니다**

```
HOLE_COUNT_VS_REFERENCE  [INFO]
  등록 공수 54공 은 설계 참고값 108공 과 다릅니다.
  C.T.C 가 구간마다 달라지므로 정상일 수 있으며, 공수의 기준은 도면 넘버링입니다.
```

`ERROR` 가 아니라 `INFO` 입니다. `error_count` 에 잡히지 않습니다.

**③ 도면이 반영된 뒤에는 도면이 기준이다**

```
HOLE_COUNT_VS_DRAWING  [WARN]
  도면에 표기된 107공 과 HOLE_MASTER 의 108공 이 다릅니다.
  도면 대조표에서 처리방식을 확인하십시오.
```

**④ C.T.C 를 구간별로 등록할 수 있다**

```
CTC  (현장 기본값)  0.47 m
CTC  구간 '곡선부'   0.40 m   ← 간격을 좁힌 구간
```

간격을 좁힌 구간이 생기면 그 구간만 따로 기록합니다.
구간별 실제 공수는 `core.v_section_hole_count` 로 언제든 셀 수 있습니다.
