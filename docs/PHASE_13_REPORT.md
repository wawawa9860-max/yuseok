## 0. 비전문가용 한 줄 요약

**계약상대방에게 보여줄 수 있는 것만, 링크 하나로 보여줍니다.**

§41 이 이 단계의 전부입니다.

> "계약상대방용에는 절대로 원가를 포함하지 않는다.
>  계약상대방 상세링크에서도 PRIVATE_COST 데이터에 접근할 수 없어야 한다."

동작은 간단합니다. **본사가 대시보드에서 버튼 하나로 링크를 발급**하면,
받은 사람은 **로그인 없이** 그 링크로 작업현황을 봅니다. §41 예시 그대로 —
금일 공수/연장, 누계, 공정률, 금일 천공번호(범위), 레미콘, 특이사항, 익일계획.

핵심은 '조심해서 안 보여주는 것' 이 아니라 **구조적으로 못 보여주는 것**입니다.
- 링크 요청은 서버가 **최소권한(EXTERNAL) DB 세션**으로 처리합니다.
  EXTERNAL 은 `private_cost` 스키마에 접근 권한 자체가 없어서 (§29),
  누가 실수로 이 경로에 원가 조회를 넣으면 **코드가 즉시 죽습니다.** 그게 의도입니다.
- 데이터는 전부 `share` 스키마 함수가 만듭니다. 함수 본문에 `private_cost` 라는
  글자가 들어가기만 해도 자동 테스트가 깨집니다.

**내부 기록도 나가지 않습니다.** 민원 같은 특이사항 사건, 인원·장비·투입공수,
비용·증빙 — 전부 외부 화면에 없습니다. 외부에 나가는 특이사항은 계약상대방과
직접 관계된 사실 둘뿐입니다: **레미콘 공급지연**과 **계획심도 미달**.

## 1. 이번에 구현한 기능

### 1.1 §41 계약상대방용 작업현황

실제 화면 (브라우저 확인분):

```
시험현장 RF CIP — RF CIP 작업현황 · 2026.08.29
  금일 14공 · 271m · 공정률 23.3%
  누계 14 / 60공
  금일 천공번호   범위 A-031 ~ A-044
  지층별 실적     토사 196m · 풍화암 84m
  레미콘          91㎥
  특이사항        레미콘 공급지연 60분 · 레미콘공장
                 계획심도 미달 A-037 11.0/20.0m · 지하수
  익일계획        A-045부터 진행예정
```

§41 예시의 **`A-031 ~ A-044 / 제외 A-037`** 형식도 구현했습니다.
같은 접두어의 연속 번호는 범위로 줄이고, 빠진 번호가 적으면 '제외' 로,
많으면 구간 나열로 표현합니다. 무근 번호(`1-1`)도 그대로 다룹니다 (§14).

### 1.2 토큰 발급·회수 (본사 승인, §29)

- **발급은 본사만.** 대시보드 현장 상세에 `[오늘 작업현황 링크 발급]` 버튼.
  기본 7일 만료 (1~90일).
- 토큰은 128비트 난수 — 추측할 수 없습니다.
- **회수하면 이미 퍼진 링크도 그 순간부터 닫힙니다.** 브라우저로 확인했습니다.
- 없는 토큰, 형식이 틀린 토큰, 만료·회수된 토큰은 **똑같이 404** 입니다.
  링크가 있는지 없는지조차 밖에서 알 수 없습니다.

### 1.3 §42 카카오톡 공유 원칙의 토대

카카오톡에는 "핵심 정보 + 상세보기 링크" 만 갑니다 (PHASE 14).
그 상세보기 링크의 실체(`/share/:token`)를 이번에 만들었습니다.
원본 자료는 시스템에 남고, 링크는 열람 전용입니다.

### 1.4 본사 미리보기

보내기 전에 **무엇이 나가는지 본사가 먼저 봅니다.**
미리보기와 외부 화면이 같은 함수를 쓰므로 다를 수가 없습니다 (테스트로 확인).

## 9. 발견된 위험

### 9.1 외부 역할이 토큰 없이 조회할 수 있는 구멍 (만들다 잡음)

처음 설계에서 `fn_daily_status` 가 "외부 역할이면 통과" 로 되어 있었습니다.
그러면 외부 DB 세션만 얻으면 **아무 현장이나** 조회할 수 있습니다.
내부 구현/배정 검사 래퍼/토큰 검사 래퍼 3단으로 분리해 진입로를 둘로 못박았고,
외부가 두 함수를 직접 부르면 `42501` 인 것을 테스트로 남겼습니다.

### 9.2 `search_path` 에 public 이 없어 pgcrypto 를 못 찾음 (고침)

보안상 함수마다 `search_path` 를 고정해 두었는데, 그래서 `gen_random_bytes` 가
안 잡혔습니다. `public.` 을 명시했습니다.

### 9.3 남아 있는 주의점

- 공개 링크에는 **접속 속도 제한이 없습니다.** 토큰이 128비트라 무차별 대입은
  비현실적이지만, 운영 배포 시 웹서버 단 rate limit 을 권합니다 (Pilot 뒤 항목).
