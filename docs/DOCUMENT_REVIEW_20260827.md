## 4. ★ 발견된 문제

### 4-1. 천공조서 합계행의 수식 참조범위가 낡았습니다 (중대)

데이터는 54공으로 늘었는데 **합계행 일부 셀이 이전 29공 범위를 그대로 참조**하고 있습니다.

| 셀 | 현재 값 | 올바른 값 | 비고 |
|---|---|---|---|
| `A61` (공수) | 29 | **54** | 29공 잔재 |
| `J61` (H-PILE 합계) | 580 | **1,080** | 29 × 20 = 580 |
| `V61` (무근 합계) | 522 | **972** | 29 × 18 = 522 |
| `C61` `E61` `G61` (지층 소계) | 810 / 162 / 108 | 정상 | 갱신됨 |

**지층 소계는 맞고 합계열만 틀립니다.** 그래서 산출근거 교차검증은 통과하는데도
H-Pile 물량만 어긋나는, 눈에 잘 띄지 않는 형태입니다.

### 4-2. 오류가 산출근거와 내역서까지 전파되었습니다

```
천공조서 J61 = 580
   ↓
산출근거 R18  H-Pile 근입      580 M      ← 올바른 값 1,080 M  (500m 누락, 46%)
산출근거 R20  H-Pile 중량      54.52 ton  ← 1,080 × 94kg/m = 101.52 ton
산출근거 R22  할증 포함        58.34 ton  ← 108.63 ton
   ↓
내역서-실행가 R20  H-PILE 근입  580 M     ← 실행원가 산정에 직접 반영
```

**H-Pile 물량이 실제의 약 54% 만 계상되어 있습니다.**

### 4-3. H-Pile 규격이 두 시트에서 다릅니다

| 시트 | 규격 | 단위중량 |
|---|---|---|
| 산출근거 R20 | `H-300x300*10*15` | 94 kg/m |
| 내역서-실행가 R20 | `H-350x350*12*19` | — |

산출근거는 H-300 으로 바뀌었으나 내역서는 H-350 이 남아 있습니다.
연결판 규격(`PL-600x200x14`, `PL-600x280x14`)도 H-300 기준으로 재검토가 필요해 보입니다.

### 4-4. 도면과 조서의 공수가 다릅니다

| | 도면 | 조서 |
|---|---|---|
| H-PILE | 54공 | 54공 ✅ |
| 무근 | **53공** (`16-1` 없음) | **54공** |
| 합계 | **107공** | **108공** |

지시하신 대로 **도면을 기준으로** 맞추면 `16-1` 을 제외해야 합니다.
다만 계약수량에 영향을 주므로 시스템이 임의로 삭제하지 않고
**대조표를 보여주고 처리방식을 선택**하게 했습니다 (§8).

### 4-5. 총 공수 계산이 맞지 않습니다 (경미)

```
가시설 연장 50m ÷ C.T.C 0.47m = 106.4공   →  조서에는 108공
```

올림 처리인지, 다른 근거가 있는지 확인이 필요합니다.

## 5. ⚠️ 실행가 시트 취급 (§29)

새 파일에는 **`갑지-실행가`, `내역서-실행가`** 두 시트가 있습니다.
여기에는 재료비·노무비·경비 **단가와 금액** 열이 있어, Master Prompt §29 가
계약상대방에게 절대 노출을 금지한 **내부 원가(PRIVATE_COST)** 에 해당합니다.

현재 조치:
- 시트 판별에서 두 시트는 `UNKNOWN` 으로 분류되어 **가져오기 대상에서 제외**됩니다.
- 자동 테스트로 고정했습니다 (`실행가 시트는 조서/산출근거로 오인하지 않는다`).
- 수량(1,620 / 324 / 108 / 1,944 / 580 / 54)은 원가가 아니므로 `core` 에 들어가도 무방하나,
  **단가·금액은 `private_cost` 스키마로만** 들어가야 합니다. PHASE 8 에서 다룹니다.

> 갑지 견적금액은 4,000,000원으로 적혀 있으나 직접공사비 단가가 모두 0 입니다.
> 단가 미기입 상태의 템플릿으로 보입니다.
