## 1. 이번에 구현한 기능

### 1.1 §40 상세보기 링크 → 딥링크 (지시: "알아서 심도있게 생각 후 진행")

**문제 인식.** 기존 링크는 앱 첫 화면으로만 갔습니다. §40 메시지를 받은 본사
담당자가 링크를 눌렀을 때 "그래서 어느 현장, 어느 날짜인가" 를 다시 찾아야 한다면
링크의 의미가 없습니다. §42 의 '상세보기 링크' 는 **누르면 그 자리로 가는 것**이어야 합니다.

**구현.**

| 링크 | 누르면 |
|---|---|
| `[현장 상세보기]` `…#report/<현장>/<날짜>` | 로그인 후 **그 현장·그 날짜의 작업일보**로 직행 |
| `[본사 원가 상세보기]` `…#cost/<현장>/<날짜>` | **본사 로그인 후** 그 현장의 원가 상세로 직행 |

- 로그인이 안 되어 있으면 로그인 화면을 거친 뒤 이어서 열립니다.
- §40 대로 **원가 링크는 본사 권한 인증 후에만** 열립니다. 현장관리자가 누르면
  "본사 계정으로만 볼 수 있습니다" 안내 후 자기 화면으로 갑니다 (§29). 브라우저로 확인했습니다.
- 배정되지 않은 현장 링크도 이유를 말하고 막습니다.
- 운영 도메인은 `.env` 의 `PUBLIC_BASE_URL` 하나로 바꿉니다.

### 1.2 카카오 공식 MCP (지시: playmcp.kakao.com)

주신 주소는 **카카오가 공식 제공하는 MCP 서버(PlayMCP)** 로, 저(Claude)와 연결되는
채널입니다. 이번 세션에 이미 연결되어 있어 **실제 전송으로 검증**했습니다 —
시험현장의 §40 보고문이 사장님 카카오톡에 가 있습니다.

세 채널의 역할:

| 채널 | 용도 | 상태 |
|---|---|---|
| **휴대폰 공유창** (PHASE 14) | 현장관리자의 일일 보고 — 키·설정 불필요, 모든 기기 | ✅ 운영 사용 |
| **PlayMCP** (카카오 공식 MCP) | Claude 와 대화하며 보고 받기 (나에게 보내기, 200자) | ✅ 실전송 확인 |
| **카카오 JS SDK** (버튼형 템플릿) | 앱 안에서 버튼형 카톡 메시지 | 카카오 개발자 앱 키 필요 — 발급 시 연결 |

### 1.3 §52 최종 성공기준 자동 점검

`server/tests/phase15-criteria.test.ts` — 각 테스트 제목이 §52 문장 그대로입니다.

| §52 기준 | 판정 | 증거 |
|---|---|---|
| ① 일일입력 3분 이내 | ✅ | 필수 입력 = 요청 1건, 화면 5터치 (브라우저 실측) |
| ② 동일 데이터 중복입력 0 | ✅ | 동시 3연발 재전송 → 1건 저장 |
| ③ 수량산출서=HOLE_MASTER=도면=천공일지 | ✅ | 서로 다른 경로 집계 일치 (§35) |
| ④ 지층별 계획수량 자동집계 | ✅ | 3층 조합 × 공수 |
| ⑤ 현장마다 다른 지층조합 | ✅ | 현장별 사용자 정의 (하드코딩 0) |
| ⑥ 천공번호 범위 일괄설정 | ✅ | spec 하나로 80공 |
| ⑦ 비용 증빙률 확인 가능 | ✅ | 건수만, 금액 0 |
| ⑧ 계약상대방 원가노출 0건 | ✅ | 의존 0 + 역할 차단 + prosrc 검사 3중 |
| ⑨ 작업일보 자동생성 | ✅ | 새로 묻는 것 없이 |
| ⑩ 카카오톡용 보고서 자동생성 | ✅ | §40/§41 + 딥링크, **실전송 확인** |
| ⑪ 50~60대 무설명 입력 | ⏳ **R20** | 사람만 판정 가능 — `PILOT_GUIDE.md` 7단계 |

### 1.4 운영 안전장치

- **운영모드 환경값 검사** — `NODE_ENV=production` 인데 개발용 시크릿/비밀번호가
  그대로거나 `PUBLIC_BASE_URL` 이 없으면, 서버가 무엇을 바꿔야 하는지 한국어로
  말하고 켜지지 않습니다. 실제 원가가 들어가는 순간부터는 봐줄 수 없는 문제입니다 (§29).
- **공개 링크 속도제한** — IP 당 분당 60회. 70회 연속 시도 → 429 확인.
- **`.env.example`** — 채워야 할 값과 만드는 법이 주석으로.
- **`docs/PILOT_GUIDE.md`** — 서버 준비부터 매일 운영 루틴까지 8단계 + R20 관찰표.

## 8. 사람이 직접 확인해야 할 사항 — Pilot 의 본체

1. **R20 실사용 시험** — `PILOT_GUIDE.md` 7단계 관찰표대로, 실제 현장관리자에게
   설명 없이 휴대폰만 주고 지켜봐 주십시오. 막힌 지점 기록이 다음 수정 목록입니다.
2. **운영 서버와 도메인** — 준비되면 `.env` 세 값만 채우면 됩니다.
3. **실제 단가·지급방식** — 본사 화면에서 직종별 일당/월급, 장비별 일대/월대.
4. **카카오 JS SDK 앱 키** — 버튼형 템플릿을 원하시면 발급해 주십시오.
5. 이월 미결: 계획 레미콘량 표기(591.498/591.493), 내역서 H-Pile 규격,
   작업일보 확정 스냅샷 여부.

## 9. 발견된 위험

  공유창 경로가 맞고, PlayMCP 는 Claude 를 통한 수신 채널로 쓰는 것이 적절합니다.
