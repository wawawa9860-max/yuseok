## 0. 비전문가용 한 줄 요약

**일일입력을 마치고 버튼 하나를 누르면 카카오톡 보고가 끝납니다.**

§0 의 목표 문장 그대로입니다 — *"현장관리자가 1~3분 안에 입력을 끝내고,
카카오톡으로 보고서를 공유한다."*

- **현장관리자** → 메인의 `[카카오톡 공유]` 를 누르면 §40 형식의 본사 보고문이
  만들어지고 휴대폰 공유창이 열립니다. 카카오톡을 고르면 끝입니다.
- **본사** → 대시보드 상세의 발급 버튼을 누르면 §41 형식의 계약상대방용
  메시지와 상세보기 링크가 함께 만들어집니다.

§42 원칙 — 메시지에는 **핵심 작업정보 + 대표 상태 + 상세보기 링크**만 들어가고,
원본 자료는 시스템에 남습니다. 카카오톡은 파일 저장소가 아닙니다.

먼저, 지난 확인사항도 반영했습니다.

> **"외부로 나가는 특이사항 모든 범위는 같이 공유가 되어야 한다."**

계약상대방용 작업현황·메시지에 **특이사항 전 범위**가 나갑니다 — 일일입력 예외
(공급지연·심도미달)에 더해 **등록된 사건 8종 전부**(민원 포함)입니다.
원가는 여전히 한 글자도 나가지 않습니다 (§41 절대 원칙은 그대로).

## 1. 이번에 구현한 기능

### 1.1 §40 본사용 메시지 (현장관리자 → 본사)

실제 생성분 (브라우저 확인):

```
[시험현장 RF CIP / 8월29일]

금일
14공 / 272m

누계
14공
공정률 23.3%

지층별 계획실적
토사 196m
풍화암 84m

레미콘
91㎥

특이사항
레미콘 공급지연 60분 · 레미콘공장
계획심도 미달 A-037 12.0/20.0m · 지하수
소음 민원발생 인근 상가 민원 접수

본사전용
비용등록 6건
증빙완료 5
증빙대기 1

[현장 상세보기]
[본사 원가 상세보기]
```

§40 대로 **"내부 원가의 구체적인 금액을 직접 넣지 않는다"** — 본사전용 블록에는
건수만 들어갑니다 (증빙 건수는 §52 상 현장관리자도 볼 수 있는 값). 금액은
`[본사 원가 상세보기]` 링크 너머, 본사 로그인 뒤에만 있습니다.

### 1.2 §41 계약상대방용 메시지 (본사 발급)

발급 버튼 하나로 **토큰 링크 + 메시지 본문**이 같이 나오고, 메시지 속 링크는
로그인 없이 열립니다 (PHASE 13). 본사전용 블록·비용·증빙은 **없습니다.**
`A-031 ~ A-044 / 제외 A-037` 범위 표현, 익일계획까지 §41 예시 그대로입니다.

### 1.3 공유 방식

휴대폰의 **기본 공유창**(`navigator.share`)을 씁니다 — 공유창에서 카카오톡을
고르면 됩니다. 공유창이 없는 기기는 자동으로 **복사**로, 그것도 안 되면 본문을
화면에 보여주고 길게 눌러 복사하게 합니다.
버튼을 눌렀는데 아무 일도 안 일어나는 경우는 없습니다.

> 카카오 공식 SDK(버튼형 메시지 템플릿)는 카카오 개발자 앱 키가 필요해
> Pilot 항목으로 남겼습니다. 지금 방식은 키 없이 모든 기기에서 동작합니다.
