# Pilot 가이드 — 실제 현장 1곳 적용 (PHASE 15)

> 대상: 본사 담당자. 이 문서 순서대로 하면 실제 현장 하나를 시스템에 올릴 수 있습니다.
> 시험 삼아 눌러보고 싶으면 `docs/TRIAL_GUIDE.md` (가짜 데이터) 를 먼저 보십시오.

---

## 1~3단계 — 서버 준비 (둘 중 하나)

**방법 A — 클라우드 (권장, 클릭만): `docs/CLOUD_DEPLOY_GUIDE.md` 순서대로.**
서버·DB·https 주소가 자동으로 생기고, DB 구조와 본사 계정까지 자동으로 만들어집니다.
끝나면 바로 이 문서 **5단계**로 오시면 됩니다.

**방법 B — 사무실 PC 직접 설치** (Node.js 20+ 와 PostgreSQL 16):

```bash
git clone <저장소 주소>
cd yuseok/server
cp .env.example .env      # 열어서 값을 채운다 (아래 표)
npm install
```

`.env.example` 의 주석대로 채웁니다. **세 가지는 반드시 바꿔야 합니다** —
안 바꾸면 운영 모드(NODE_ENV=production)에서 서버가 이유를 말하고 켜지지 않습니다.

| 항목 | 만드는 법 |
|---|---|
| `JWT_SECRET` | 아무 문자열 32자 이상 (`openssl rand -hex 32` 결과 권장) |
| `APP_DB_PASSWORD` | 강한 비밀번호 (`DATABASE_URL` 은 비워 두면 자동 조립됩니다) |
| `PUBLIC_BASE_URL` | 운영 주소 (예: `https://rfcip.회사도메인.com`). 카카오톡 링크가 이 주소로 만들어진다 |

```bash
NODE_ENV=production INITIAL_ADMIN_PASSWORD=본사비밀번호 npm run build && \
NODE_ENV=production INITIAL_ADMIN_PASSWORD=본사비밀번호 npm start
```

켜지면서 DB 구조 적용과 본사 계정(`admin`) 생성이 자동으로 됩니다.

## 4단계 — 계정 만들기 (웹에서)

`admin` 으로 로그인 → 본사 대시보드 → **[계정 관리]** →
현장관리자 계정을 만들고 아이디·비밀번호를 당사자에게 전달합니다.
비밀번호를 잊으면 같은 화면에서 재설정하고, 퇴사자는 지우지 말고 **중지**합니다.
psql 도 파일 수정도 필요 없습니다.

## 5단계 — 현장 최초설정 (본사, PC 권장)

본사 계정으로 로그인하면 대시보드가 열립니다. 현장설정 단계가 안내하는
**사전 업로드 5종** 순서대로 올립니다.

```
① 계약내역서   ← 단가는 여기 있습니다. 천공에 단가를 붙이지 않습니다
② 천공조서     ← 계획심도의 기준
③ 수량산출서   ← 미리보기 → 오류 확인 → 승인 → 반영
④ 공내역서
⑤ 작업도면(평면도 넘버링) ← 천공번호·공수의 기준
```

이어서: 천공번호 생성 → 지층종류(현장 용어로) → 지반조건/계획심도 →
계약수량 → **천공종류 ↔ 계약내역 품목 연결** → 기본 인원/장비 →
노무·장비 단가(본사만 보임) → 검증에서 ERROR 0 확인.

## 6단계 — 현장관리자 휴대폰 설정 (5분)

1. 카카오톡으로 접속 주소를 보낸다 → 현장관리자가 열고 로그인
2. **홈 화면에 추가** (Safari: 공유 → 홈 화면에 추가 / Chrome: ⋮ → 홈 화면에 추가)
3. **통신 되는 곳에서 앱을 한 번 연다** — 이때 현장 자료가 휴대폰에 저장되어
   현장에서 통신이 끊겨도 입력할 수 있습니다

## 7단계 — 하루 돌려보기 (R20 실사용 시험)

현장관리자에게 **설명 없이** 휴대폰만 주고 지켜봅니다.

| 관찰 항목 | 통과 기준 |
|---|---|
| 오늘 작업 입력 | 도움 없이 3분 이내 |
| 계획심도 못 간 공 처리 | [못 간 공 있다] 를 스스로 찾는가 |
| 비용 + 영수증 사진 | 사진 찍기까지 스스로 |
| 카카오톡 공유 | 보고문이 본사 방에 도착 |
| 막힌 곳 | **어디서 멈췄는지 그대로 기록** — 그게 다음 수정 목록입니다 |

## 8단계 — 매일 운영 루틴

```
현장: 퇴근 전 [오늘 작업 입력] → [카카오톡 공유]
본사: 대시보드에서 이상표시 현장만 클릭 → 필요 시 [계약상대방 공유] 발급
월말: 본사 [월 원가계산] → 기성 초안 → 제출 → 승인
```

## 자주 묻는 것

- **통신이 안 되는 현장인데요?** — 6단계 3번만 지키면 됩니다. 입력은 휴대폰에
  쌓였다가 통신되면 자동 전송되고, 두 번 저장되지 않습니다.
- **링크를 잘못 보냈어요** — 본사 대시보드에서 회수하면 그 즉시 열리지 않습니다.
- **서버가 안 켜져요** — 화면의 한국어 안내를 읽으십시오. 포트 충돌·환경값 누락은
  서버가 이유를 말해줍니다.
