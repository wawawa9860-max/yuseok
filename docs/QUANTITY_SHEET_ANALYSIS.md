# 수량산출서 구조 분석 (실제 샘플 기준)

> 분석 대상: 사용자 업로드 RF-CIP 수량산출서 (2 시트)
> 목적: PHASE 4(수량산출서 ↔ HOLE_MASTER 연결) 설계 근거 확보
> 원칙: **원본의 산출방식을 임의로 바꾸지 않는다** (Master Prompt §9 후단, §11)

---

## 1. 시트 구성

| 시트 | 성격 | HOLE_MASTER 와의 관계 |
|---|---|---|
| `산출근거(RF-CIP)` | 지층별 **집계** + 파생 공종(케이싱/H-Pile/콘크리트/잔토/가이드월) | 검증용 합계 |
| `천공조서(RF-CIP)` | 천공번호별 **명세** | **HOLE_MASTER 의 원천** |

## 2. 천공조서 — 실제 레이아웃

헤더가 3행(R3~R5)에 걸친 **2단 병합 구조**이고, 좌·우 두 블록이 나란히 있다.

R5  H-PILE   │공당│소계│공당│소계│공당│소계│공당│소계│합계│      │  무근   │공당│소계│…│합계│
R6     1     │14.6│14.6│2.4 │2.4 │ 0  │ 0  │ 0 │ 0 │ 17 │  1   │   1.1   │14.6│14.6│…│ 17 │

## 3. 이 샘플에서 확인된 사실

### 3.1 천공번호는 `A-001` 형식이 아니다 ★

| 천공종류 | 실제 번호 | 개수 |
|---|---|---|
| H-PILE 구간 | `1`, `2`, `3` … `29` | 29공 |
| 무근 | `1.1`, `1.2` … `3.9` | 29공 |

**순수 정수와 소수점 표기가 함께 쓰인다.** 현장·도면마다 다르므로
시스템이 번호 형식을 강제하면 안 된다. → PHASE 2에서 정렬방식을 교체했다(§4 참조).

### 3.2 지층 열은 4개가 인쇄되지만 실제 사용은 2개

| 지층 | 총 연장 | 사용 |
|---|---|---|
| 토사 | 876.12 m | ✅ |
| 풍화암 | 147.30 m | ✅ |
| 연암 | 0 m | ❌ (열만 존재) |
| 경암 | 0 m | ❌ (열만 존재) |

**값이 0인 지층 열은 그 현장의 지층종류로 등록하지 않는다.**
GROUND_TYPE 을 현장별 사용자 정의로 만든 설계가 그대로 들어맞는다 (§7).

### 3.3 공당 깊이가 천공번호마다 다르다 ★

```
PILE  1 : 토사 14.60 + 풍화암 2.40 = 17.00 m
PILE  4 : 토사 14.63 + 풍화암 2.37 = 17.00 m
PILE 13 : 토사 15.01 + 풍화암 3.09 = 18.10 m
PILE 29 : 토사 15.70 + 풍화암 2.40 = 18.10 m
```

즉 **범위 일괄적용(§10)만으로는 부족하고, 공별 원본값 적용(§11 후단)이 반드시 필요하다.**
현재 스키마는 둘 다 지원한다.
- 범위 공통 → 여러 hole 이 하나의 `ground_profile` 을 참조
- 공별 상이 → hole 마다 `ground_profile` 1개 (1:1)

지층합계 = 총심도 검증은 두 경우 모두 그대로 작동한다.
(예: 14.60 + 2.40 = 17.00 ✅ / 15.01 + 3.09 = 18.10 ✅)

### 3.4 설계 파라미터 (현장 단위)

| 구분 | 값 | 단위 | 비고 |
|---|---|---|---|
| 직경 | 0.6 | m | 설계값 |
| C.T.C | 0.47 | m | 중심간거리 |
| 가시설 연장 | 300 | m | 벽면 연장 |
| 측면말뚝 간격 | 1.41 | m | |
| 총 공수 | 638.30 | 공 | 연장 ÷ C.T.C |
| H-PILE 본수 | 212.77 | 본 | 총공수 ÷ 3 |
| 무근 본수 | 425.53 | 본 | 총공수 − H-PILE |

> ⚠️ 이 샘플의 천공조서에는 **29공만** 기재되어 있다(총 공수 638.30공과 불일치).
> 대표 구간만 발췌한 조서로 보인다. **사람이 확인해야 할 사항이다.**

### 3.5 계획 레미콘량 산출식 (산출근거 R32~R36)

```
타설량 = (3.14 × 0.6²) / 4 × 총천공연장(1,023.42 m) = 289.22 m³
할증   = 289.22 × 2%                                =   5.78 m³
계     =                                               295.00 m³
```

→ **공당 계획 레미콘 = 0.2826 m³/m** (직경 0.6m, π=3.14, 할증 2%)

PHASE 1 시드의 `0.196 m³/m`(D500 가정)은 **이 현장 기준이 아니다.**
직경·할증률은 현장 설계 파라미터로 받아야 한다. → PHASE 7 레미콘 단계에서 반영.

### 3.6 산출근거 ↔ 천공조서 교차검증이 성립한다

```
산출근거 토사   876.12 = 천공조서 H-PILE 438.06 + 무근 438.06  ✅
산출근거 풍화암 147.30 = 천공조서 H-PILE  73.65 + 무근  73.65  ✅
케이싱튜브     1,023.42 = 876.12 + 147.30                       ✅
H-Pile 근입      511.71 = 천공조서 H-PILE 합계                  ✅
```

**PHASE 4의 자동검증 항목으로 그대로 사용한다.**

## 4. PHASE 4 가져오기 설계 방향 (예고)

Master Prompt §12 순서를 따르되, 이 샘플 구조를 근거로 다음을 준비한다.

1. 시트 자동판별 — 이름에 `천공조서` 포함 시트를 명세로, `산출근거` 포함 시트를 검증용으로
2. 다단 헤더 파싱 — R3~R5 병합 헤더에서 `지층명 × (공당|소계)` 매트릭스 복원
3. 좌·우 블록 분리 — `PILE NO.` 열이 2회 이상 등장하면 천공종류가 다른 별개 블록
4. 값이 0인 지층 열은 GROUND_TYPE 후보에서 **제외** 후 사용자 확인
5. 공당 값으로 hole 별 GROUND_PROFILE 생성 → 지층합계 = 합계열(J/V) 검증
6. 합계행(R36)과 산출근거 집계를 교차검증
7. **미리보기 → 사용자 승인 → 반영** (AI가 계약수량을 자동 확정하지 않는다, §12/§45)

---

## 5. 사람이 확인해야 할 사항

1. 천공조서 29공 vs 설계 총공수 638.30공 — 발췌본인지, 이 조서가 전부인지
2. 무근 번호 `1.1 ~ 3.9` 의 의미 (H-PILE 사이 삽입 순번으로 추정)
3. `1차 천공(무근)` / `2차 천공(절삭공)` 과 천공종류 매핑이 맞는지
4. 연암·경암 열은 항상 인쇄되는 양식인지 (현장별 지층종류 등록 시 판단 근거)
