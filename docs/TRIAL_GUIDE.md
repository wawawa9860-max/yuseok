# 시험사용 가이드 — 현장관리자에게 그냥 건네주기

> 목적: Master Prompt §52 성공기준 중 **"50~60대 사용자가 별도 설명 없이 기본입력 가능"** 을 확인한다.
> 이것은 개발자가 확인할 수 없다. 실제 현장관리자만 확인할 수 있다.

---

## 1. 왜 지금 해야 합니까

PHASE 7까지 오면서 기능은 계속 쌓였는데, **실제 현장관리자가 아직 한 번도 써본 적이 없습니다.**

지금 구조를 바꾸는 것과 PHASE 12쯤에 바꾸는 것은 비용이 다릅니다.
지금은 화면이 두 개뿐이라 갈아엎어도 하루면 됩니다.

---

## 2. 준비 — 셋 중 하나를 고르십시오

### 방법 A. Docker 로 한 번에 (권장, PC 한 대만 있으면 됨)

```bash
git clone https://github.com/wawawa9860-max/yuseok
cd yuseok
git checkout claude/master-prompt-phase-1-3pvbl2
docker compose up
```

PostgreSQL 과 서버가 같이 뜨고, 시험용 현장까지 자동으로 만들어집니다.
처음 한 번은 5분쯤 걸립니다.

### 방법 B. 이미 PostgreSQL 이 있다면

```bash
cd yuseok
cp server/.env.example server/.env      # 접속정보 수정
npm --prefix server install
npm --prefix server run trial           # 초기화 + 시험현장 + 서버 실행
```

### 방법 C. 인터넷으로 접근해야 한다면

현장과 사무실이 떨어져 있으면 A·B 로는 안 됩니다.
클라우드(Render / Railway / Fly.io 등)에 올려야 하는데, 이건 별도 작업입니다.
**첫 시험은 A 나 B 로 사무실에서 하시는 것을 권합니다.**

## 3. 휴대폰으로 접속

서버를 띄우면 화면에 이렇게 나옵니다.

```
  RF CIP Mobile Field Control
  이 PC에서          http://localhost:3000/app/
  같은 Wi-Fi 휴대폰   http://192.168.0.15:3000/app/

  ▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄
  █ ▄▄▄▄▄ ██▄▄ ▀ ██     ← 휴대폰 카메라로 찍으면 바로 열립니다
  █ █   █ █▀▄  █▀ ▀█
  ...
```

**휴대폰과 PC 가 같은 Wi-Fi 에 있어야 합니다.**

접속 후 브라우저 메뉴에서 **`홈 화면에 추가`** 를 누르면 앱처럼 아이콘이 생깁니다.
(아이폰 Safari: 공유 → 홈 화면에 추가 / 안드로이드 Chrome: ⋮ → 앱 설치)

### 시험 계정

```
아이디    trial
비밀번호  test1234!
```

시험현장에는 **A-001 ~ A-060, 60공**이 미시공 상태로 들어 있습니다.
공당 20m (토사 14m + 풍화암 6m), 기본 인원 4명, 기본 장비 3대가 설정되어 있습니다.

## 4. ★ 시험 방법 — 아무 설명도 하지 마십시오

§52 는 **"별도 설명 없이"** 기본입력이 가능해야 한다고 합니다.
그러므로 설명하면 시험이 성립하지 않습니다.

### 이렇게 하십시오

1. 휴대폰을 켜서 앱을 열어 둔 상태로 건넨다 (로그인까지만 해 둔다)
2. **딱 이 한 문장만** 말한다

   > "오늘 A-001번부터 A-013번까지 뚫었다고 치고, 입력해 보세요."

3. **그 다음부터는 아무 말도 하지 않는다.** 물어봐도 답하지 않는다.
   ("저기 저 파란 버튼이요" 같은 말을 하는 순간 시험은 끝난 것입니다)
4. 옆에서 **시간을 재고 관찰만** 한다

### 관찰할 것

| 관찰 항목 | 기록 |
|---|---|
| 첫 화면에서 뭘 눌러야 할지 **몇 초 만에** 찾았는가 | ___초 |
| 헤맨 지점이 있었는가 (어느 화면, 무엇을 찾다가) | |
| 물어본 것이 있는가 (무엇을) | |
| 입력완료까지 **총 몇 분** 걸렸는가 | ___분 ___초 |
| 글씨가 작다고 했는가 | 예 / 아니오 |
| 버튼을 잘못 눌렀는가 (몇 번) | ___회 |
| 끝내고 나서 **뭘 한 건지 이해했는가** | |

### 두 번째 시험 (같은 사람, 5분 뒤)

같은 사람에게 한 번 더 시킵니다. 이번엔 **A-014 ~ A-020**.

> 처음보다 **눈에 띄게 빨라지면** 화면 구조는 배울 만한 것입니다.
> 두 번째도 헤매면 **구조 자체를 고쳐야 합니다.**

## 5. 합격 기준 (§52)

| 기준 | 합격선 |
|---|---|
| 설명 없이 입력 완료 | **가능해야 함** |
| 소요 시간 | 첫 시도 3분 이내, 두 번째 1~2분 |
| 물어본 횟수 | 0~1회 |
| 글씨 크기 불만 | 없어야 함 |

**하나라도 미달이면 알려주십시오.** 그것이 다음에 고칠 것입니다.

## 6. 함께 봐 주시면 좋은 것

시험이 끝난 뒤 물어봐 주십시오.

1. **"이 화면에 없어서 불편한 게 뭡니까?"**
   → 순서를 바꿔야 할 수도 있습니다.
2. **"하루에 두 구간을 따로 뚫는 날이 있습니까?"**
   → 지금은 한 번에 한 범위만 고릅니다.
3. **"천공번호가 60개가 아니라 600개면 어떻겠습니까?"**
   → 목록이 길어지는 문제(R21)를 실제 사용자가 어떻게 느끼는지.
4. **"레미콘은 하루에 몇 번 나눠 받습니까?"**
   → 지금은 하루 1건(총량)입니다.

## 7. 통신 끊김도 함께 시험해 보십시오

현장은 통신이 자주 끊깁니다. 시험해 볼 수 있습니다.

1. 입력 화면까지 들어간 뒤 **휴대폰을 비행기모드로** 바꾼다
2. 그대로 입력하고 `입력완료` 를 누른다
3. → **"통신이 안 되어 저장 대기로 넘겼습니다"** 가 떠야 합니다
4. 비행기모드를 끈다
5. → 잠시 뒤 자동으로 전송되고 숫자가 반영돼야 합니다

**이때 숫자가 두 배가 되면 안 됩니다.** (재전송 중복 방지)
